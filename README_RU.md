# DT Team Pro Bot

Профессиональный Telegram-бот для продажи доступа к ежедневным товарным подборкам.

## Модель

- цена: 20 USDT;
- срок доступа: 5 дней;
- каждый день: 2 товара;
- всего за период: до 10 товаров;
- оплата: Crypto Bot / Crypto Pay;
- автоматическая активация после оплаты.

## Функции клиента

- фирменное меню DT Team;
- покупка доступа;
- автоматическая проверка платежа;
- товары за сегодня;
- архив полученных товаров;
- профиль и срок доступа;
- персональная реферальная ссылка;
- промокоды;
- поддержка.

## Функции администратора

- загрузка двух товаров на выбранную дату;
- предпросмотр контента;
- ручная рассылка;
- выдача доступа вручную;
- создание промокодов;
- общая рассылка;
- статистика пользователей, оплат и выручки;
- просмотр календаря контента.

## Запуск в Railway

1. Распакуйте архив.
2. Создайте приватный репозиторий GitHub.
3. Загрузите в него все файлы из папки.
4. В Railway выберите Deploy from GitHub Repo.
5. Добавьте Variables из `.env.example`.
6. Создайте Volume с путём `/app/data`.
7. После тестирования замените `CRYPTO_PAY_NETWORK=testnet` на `mainnet`.

## Где взять токены

### Telegram

Откройте `@BotFather`, создайте бота командой `/newbot` и получите `BOT_TOKEN`.

### Telegram ID

Откройте `@userinfobot`. Число из ответа укажите в `ADMIN_IDS`.

### Crypto Pay

Создайте приложение через официальный `@CryptoBot`.
Для тестов используйте `@CryptoTestnetBot`.

## Управление

Отправьте боту `/admin`.

Основные команды:

- `/admin` — панель администратора;
- `/addday` — добавить два товара;
- `/grant USER_ID DAYS` — выдать доступ;
- `/promo CODE DAYS USES` — создать промокод;
- `/broadcast` — сообщение всем пользователям;
- `/sendtoday` — разослать сегодняшние товары;
- `/stats` — статистика;
- `/cancel` — отменить действие.

## Формат товарной карточки

Для каждого товара бот попросит:

1. название;
2. краткое описание;
3. цену закупки;
4. рекомендуемую цену продажи;
5. площадки или рекомендации;
6. изображение.

## Важное замечание

Crypto Pay технически поддерживает создание и проверку счетов. Владелец проекта самостоятельно отвечает за соблюдение правил Telegram, правил платёжного сервиса и применимого законодательства.
