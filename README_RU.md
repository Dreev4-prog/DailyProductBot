# DT Team — упрощённое добавление товаров

Теперь администратор добавляет товар всего за пять шагов:

1. категория;
2. название товара;
3. описание;
4. картинка;
5. цена.

## Как обновить

1. Распакуйте архив.
2. В GitHub откройте текущий репозиторий.
3. Нажмите `Add file` → `Upload files`.
4. Загрузите все файлы из архива с заменой.
5. Нажмите `Commit changes`.
6. Railway автоматически выполнит новый deploy.

Переменные Railway менять не нужно.

## Добавление товара

Откройте:

```text
/admin
```

Нажмите:

```text
➕ Добавить товар в базу
```

Бот последовательно запросит категорию, название, описание, картинку и цену.
