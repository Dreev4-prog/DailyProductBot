# DT Team Random Pro

Обновлённая версия бота с персональной случайной выдачей товаров.

## Что изменилось

- товары больше не привязаны к конкретной дате;
- администратор формирует общую базу;
- каждый подписчик ежедневно получает случайные товары;
- одному пользователю товар второй раз не выдаётся;
- у разных подписчиков подборки могут отличаться;
- бот запоминает историю каждой выдачи;
- пользователь не может получить больше дневного лимита кнопкой;
- архив показывает последние полученные товары.

## Как обновить уже работающий проект

1. Распакуйте архив.
2. В GitHub откройте текущий репозиторий `DailyProductBot`.
3. Замените файлы:
   - `bot.py`
   - `README_RU.md`
   - `.env.example`
4. `requirements.txt`, `Procfile` и остальные файлы можно тоже заменить.
5. Нажмите `Commit changes`.
6. Railway автоматически выполнит новое развёртывание.
7. Существующие переменные Railway менять не нужно.
8. Существующие пользователи и платежи сохранятся, если Railway Volume подключён к `/app/data`.

## Как добавить товар

В боте откройте:

```text
/admin
```

Затем нажмите:

```text
➕ Добавить товар в базу
```

Бот запросит:

1. название;
2. категорию;
3. описание;
4. цену закупки;
5. рекомендуемую цену продажи;
6. площадки;
7. изображение.

Каждый товар загружается один раз в общую базу.

## Как работает выдача

При ежедневной рассылке бот:

1. находит активных подписчиков;
2. для каждого пользователя смотрит историю;
3. исключает уже полученные им товары;
4. случайно выбирает нужное количество;
5. отправляет и сохраняет результат.

Для тарифа 5 дней × 2 товара рекомендуется иметь минимум 10 товаров, но для реального разнообразия лучше загрузить 50–100 и больше.

## Команды администратора

- `/admin` — админ-панель;
- `/addproduct` — добавить товар;
- `/sendtoday` — выполнить сегодняшнюю выдачу;
- `/grant USER_ID DAYS` — выдать доступ;
- `/promo CODE DAYS USES` — создать промокод;
- `/stats` — статистика;
- `/cancel` — отменить операцию.

## Важно

Перед заменой файлов убедитесь, что в Railway создан Volume:

```text
/app/data
```

Без Volume база может потеряться при повторном развёртывании.
