# DT Team 3.0 — Complete Admin Panel

Полная версия Telegram-бота DT Team для продажи пятидневного доступа к персональным товарам.

## Пользовательская логика

- После оплаты активируется доступ на 5 дней.
- Каждый календарный день пользователь может получить 2 товара.
- Перед каждым товаром он выбирает категорию: `50–100 €`, `100–200 €` или `200–500 €`.
- Первый и второй товар могут быть из одной либо разных категорий.
- Товар выбирается случайно внутри выбранной категории.
- Один товар не выдаётся одному пользователю повторно.
- После двух выдач категории блокируются до 00:00 по `TIMEZONE`.

## Админ-панель `/admin`

- добавление товара с выбором категории кнопкой;
- редактирование, скрытие, корзина, восстановление и окончательное удаление;
- подробная статистика пользователей, оплат, выдач и категорий;
- рассылка текста, фото, видео, GIF и документов;
- предпросмотр и подтверждение рассылки;
- отчёт о доставленных и недоставленных сообщениях;
- добавление и удаление дополнительных администраторов из бота;
- главные администраторы из `ADMIN_IDS` защищены от удаления;
- проверка настроек платежей.

## Оплата

Включены Crypto Bot и актуальная интеграция xRocket через `https://pay.xrocket.tg`.

## Установка

1. Распакуйте архив.
2. Загрузите всё содержимое в корень GitHub-репозитория с заменой файлов.
3. Сделайте Commit changes.
4. Дождитесь завершения нового Railway deployment.
5. Проверьте `/start`, `/admin` и `/paymentstatus`.

Для сохранения SQLite между деплоями Railway Volume должен быть подключён к `/app/data`.
