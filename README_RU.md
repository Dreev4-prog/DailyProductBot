# DT Team V2

Профессиональная версия Telegram-сервиса персональных товарных подборок.

## Что входит

### Пользовательская часть

- покупка доступа на 5 дней;
- Crypto Bot и xRocket;
- 2 персональных товара ежедневно;
- отсутствие повторов для одного пользователя;
- выбор категорий;
- выбор бюджета;
- архив полученных товаров;
- избранное;
- обратная связь: «Продал», «Ещё продаю», «Не подошёл»;
- профиль и личная статистика;
- реферальная программа;
- промокоды;
- уведомление об окончании доступа.

### Администратор

- Telegram-панель;
- простое добавление товара:
  1. категория;
  2. название;
  3. описание;
  4. изображение;
  5. цена;
- список и отключение товаров;
- пользователи;
- ручная выдача доступа;
- рассылки;
- аналитика;
- веб-панель через браузер;
- загрузка товаров через веб-форму.

## Обновление существующего проекта

1. Скачайте и распакуйте архив.
2. Откройте текущий репозиторий GitHub.
3. Удалите старые программные файлы или загрузите новые с заменой.
4. Сохраните `.env.example`, но реальные токены добавляйте только в Railway Variables.
5. Нажмите Commit changes.
6. Railway автоматически выполнит новый deploy.
7. Убедитесь, что Volume подключён к `/app/data`.

Старая SQLite-база не используется автоматически, потому что структура V2 отличается. Пользователи снова зарегистрируются при `/start`. При необходимости данные можно мигрировать отдельно.

## Переменные Railway

Обязательные:

```text
BOT_TOKEN
ADMIN_IDS
DATABASE_PATH=/app/data/dt_team_v2.db
WEB_ADMIN_PASSWORD
```

Для Crypto Bot:

```text
CRYPTO_PAY_ENABLED=true
CRYPTO_PAY_TOKEN=...
CRYPTO_PAY_NETWORK=testnet
```

Для xRocket:

```text
XROCKET_ENABLED=true
XROCKET_TOKEN=...
XROCKET_NETWORK=testnet
XROCKET_ASSET=USDT
```

### Сети

- Crypto Bot testnet: токен из `@CryptoTestnetBot`.
- Crypto Bot mainnet: токен из `@CryptoBot`.
- xRocket testnet: тестовый Bearer token.
- xRocket mainnet: рабочий Bearer token.

## Веб-панель

В Railway:

1. Откройте Settings сервиса.
2. В разделе Networking нажмите Generate Domain.
3. Откройте полученный адрес.
4. Введите `WEB_ADMIN_USERNAME` и `WEB_ADMIN_PASSWORD`.

Не используйте пароль из примера.

## Запуск и проверка

После успешного deploy:

1. Откройте бота.
2. Нажмите `/start`.
3. Администратор отправляет `/admin`.
4. Добавьте минимум 10 товаров.
5. Для теста выдайте себе доступ:

```text
/grant ВАШ_TELEGRAM_ID 5
```

6. Нажмите «Получить товары».

## Команды

```text
/admin
/grant USER_ID DAYS
/promo CODE DAYS USES
/broadcast
/sendtoday
/paysupport
/cancel
```

## Важное ограничение Telegram

Доступ к цифровым материалам внутри Telegram официально относится к цифровым товарам или услугам. Telegram требует Telegram Stars для таких продаж. Crypto Bot и xRocket добавлены технически, но владелец самостоятельно принимает решение об их использовании и отвечает за соблюдение правил Telegram и применимого законодательства.
