# DT Team 5.0.0

## Новое

- Умный поиск товаров по названию, описанию, категории и подготовленным тегам.
- Автоматическая проверка похожих товаров сразу после ввода названия.
- Кнопки: открыть похожий товар, всё равно добавить или отменить.
- Центр управления товарами с фильтрами по категориям и статусу.
- Раздел популярных товаров по количеству выдач и добавлений в избранное.
- В карточке товара показываются дата добавления, число выдач и избранного.
- Индексы PostgreSQL для поиска и фильтрации.
- Автоматическая миграция: колонка `tags` создаётся при запуске.

## Обновление Railway

Замените файлы проекта в GitHub содержимым архива. Railway выполнит деплой автоматически. Новые поля и индексы создаются функцией `init_db()`, существующие товары и пользователи не удаляются.

## Важно

Перед проверкой поиска дождитесь сообщения Railway о запуске polling. При добавлении товара проверка дубликатов запускается после ввода названия.
