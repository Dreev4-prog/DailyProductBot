# DT Team 4.0 — PostgreSQL

## Что изменилось

- Основная база теперь PostgreSQL.
- Бот подключается через Railway-переменную `DATABASE_URL`.
- Таблицы и индексы создаются автоматически при первом запуске.
- Сохранены все возможности версии 3.3, включая 1–6 фотографий товара.
- Добавлена попытка автоматического переноса старой SQLite-базы.

## Переменные

Обязательно:

- `DATABASE_URL` — ссылка на PostgreSQL из Railway.

Дополнительно:

- `DATABASE_POOL_SIZE=5`
- `MIGRATE_SQLITE_ON_START=true`
- `SQLITE_MIGRATION_PATH=/app/data/dt_team_v2.db`

## Важное ограничение переноса

Старая SQLite-база переносится только тогда, когда файл действительно доступен новому контейнеру по `SQLITE_MIGRATION_PATH`. Если Volume ранее не был подключён, старый файл может отсутствовать после нового деплоя. Тогда PostgreSQL начнёт работу как новая пустая база.
